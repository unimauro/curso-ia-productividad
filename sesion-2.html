Sesión 2 · Dashboards y presentaciones con IA

Jueves 1 de octubre · AI Productivity Engineering · eIA. Cuatro retos de 30 minutos: 10 de demo y 20 para construir.

Hoy vas a construir: un dashboard del Excel de la tarea publicado con tu propia URL, una presentación de 5 láminas para el gerente y un tablero que se actualiza solo cuando cambian los datos.

Antes de empezar

  • Descarga el Excel de la empresa ficticia: Tarea-S1-Estado-Financiero.xlsx.
  • Ten abiertas estas cuentas, todas gratis: GitHub, Vercel (entra con tu cuenta de GitHub) y una cuenta de Google.
  • Usa el asistente que prefieras: Claude, ChatGPT, Gemini o Grok.
  • Elige tu ruta: Ruta ventas sin código, o Ruta código con tu editor.

Reto 1 · Dashboard con IA

Sube el Excel a tu asistente y pega este prompt:

Actúa como analista financiero y desarrollador web. Adjunto el Excel de Comercial Andina S.A.C., una empresa ficticia. Crea un dashboard en UN solo archivo HTML llamado index.html, usando Chart.js desde un CDN. Incluye estos indicadores para 2023, 2024 y 2025: ventas netas, margen bruto, margen neto, días de cobranza, liquidez corriente y endeudamiento (total pasivo / patrimonio). Agrega un gráfico de ventas mensuales 2025 por región. Reglas: usa solo los datos del archivo. Debajo de cada indicador muestra la fórmula que usaste. Diseño limpio que se vea bien en el celular. Al final, lista los números que debo verificar en Excel.

Ruta ventas

  1. Descarga el archivo index.html que te dé el asistente. En Claude aparece como artefacto; en ChatGPT pídele "dame el archivo para descargar".
  2. Ábrelo con doble clic en tu navegador y revisa que se vea bien.

Ruta código

  1. Crea una carpeta dashboard-andina y pide a Claude Code o Cursor que genere el index.html leyendo el Excel.
  2. Pídele además que separe los datos en un archivo datos.json.

Reto 2 · Publícalo gratis en Vercel

Ruta ventas, todo desde el navegador

  1. En GitHub, pulsa New repository. Nombre: dashboard-andina. Marca Public y Add a README file. Pulsa Create repository.
  2. Dentro del repositorio: Add file → Upload files. Arrastra tu index.html y pulsa Commit changes.
  3. En Vercel: Add New… → Project. Busca dashboard-andina y pulsa Import, luego Deploy. No cambies ninguna configuración.
  4. Copia la URL que termina en .vercel.app. Esa es tu entrega del reto.

Ruta código

cd dashboard-andina
git init && git add . && git commit -m "Dashboard Comercial Andina"
gh repo create dashboard-andina --public --source=. --push
# luego en vercel.com: Add New → Project → Import → Deploy
# o desde la terminal:
npx vercel --prod

Cada vez que subas un cambio a GitHub, Vercel publica la nueva versión sola. El plan gratuito Hobby es solo para uso personal y no comercial. La URL es pública: nunca publiques datos reales de clientes.

Reto 3 · Presentación con IA

Usa Gamma (400 créditos gratis, suficientes para unas 10 presentaciones, con marca de agua), o pide a Claude o ChatGPT un archivo PowerPoint. Pega este prompt junto con tus resultados verificados:

Crea una presentación de 5 láminas para el gerente de Comercial Andina S.A.C.: 1. Título con la conclusión principal en una frase. 2. Las ventas suben pero el margen neto cae: muestra las cifras de 2023 a 2025. 3. Por qué: cobranza más lenta, más inventario y más deuda de corto plazo, con cifras. 4. Dos recomendaciones con el impacto esperado. 5. Próximos pasos y responsables. Usa solo estas cifras verificadas. Una idea por lámina y poco texto.
  • Revisa cada cifra contra la tabla de control del reto 1.
  • Exporta en PDF o PowerPoint, o copia el enlace para compartir.

Reto 4 · Tablero que se actualiza solo

Ruta ventas: Google Sheets y Looker Studio

  1. Sube el Excel a Google Drive y ábrelo con Google Sheets. Guárdalo como hoja de Google.
  2. Entra a Looker Studio → Crear → Informe → conector Hojas de cálculo de Google → elige tu archivo y la hoja Ventas mensuales 2025.
  3. Agrega un gráfico de barras por región y una tarjeta con el total de ventas.
  4. Cambia un número en la hoja. En Looker Studio pulsa Actualizar datos y mira cómo cambia el tablero.
  5. Pulsa Compartir y copia el enlace.

Ruta código: tu dashboard lee la hoja

  1. En Google Sheets: Archivo → Compartir → Publicar en la web, elige la hoja y el formato CSV. Copia el enlace.
  2. Pide a tu agente de código que el index.html lea ese CSV con fetch y dibuje los gráficos con esos datos.
  3. Sube el cambio a GitHub. Vercel lo publica solo. Cuando cambies la hoja, el dashboard mostrará los nuevos datos en unos minutos.

Publicar en la web hace pública esa hoja. Úsalo solo con datos de práctica.
