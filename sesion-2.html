Sesión 2 · Dashboards y presentaciones con IA

Jueves 1 de octubre · AI Productivity Engineering · eIA. Cuatro retos de 30 minutos: 10 de demo y 20 para construir.

Hoy vas a construir: un dashboard que cuenta la historia de una distribuidora; tu primera API; un agente analista que conversa y consulta tus ventas con modelos gratis; un tablero que se actualiza solo desde una hoja de Google; y Claude conectado a los datos con MCP.

Empresa ficticia que vende café, granos andinos, bebidas, snacks y limpieza en Lima, Norte, Sur y Centro. Un año completo de ventas 2025: 4.451 líneas de pedidos, 140 clientes, 6 vendedores, 6 proveedores y sus entregas.

Reto 1 · Un dashboard con alma

Un dashboard no es una pila de gráficos: cuenta una historia y dice qué hacer. Pega este prompt en v0 (ruta ventas) o en tu agente de código (ruta código):

Crea el dashboard "Pulso de Ventas · Distribuidora Andina", una empresa ficticia de alimentos y limpieza en Perú. Datos: lee el JSON de https://unimauro.github.io/curso-ia-productividad/material/ventas-2025.json. Cada fila es un producto vendido en un pedido de 2025, con los campos fecha, mes, region, canal, vendedor, producto, categoria, proveedor, venta, costo, margen, descuento y estado_pago. Quiero que cuente una historia, no solo números: 1. Un titular arriba con el hallazgo principal del año, en una frase, escrito a partir de los datos. 2. Tarjetas con ventas totales, margen %, pedidos y dinero vencido por cobrar, con un semáforo verde, ámbar o rojo. 3. Gráficos de ventas por mes, por región, por canal (Tienda, Mayorista, Online, WhatsApp) y el top 5 de productos. 4. Filtros por mes, región, canal y vendedor que actualicen todo. 5. Una sección "Alertas" que detecte sola: el vendedor con más descuento, la región o categoría que cae, y el canal que crece. 6. Una sección "Qué haría mañana el gerente" con 3 acciones concretas. Estilo: cálido y profesional, en español, montos en soles (S/), se ve bien en el celular y tiene modo oscuro. Usa solo los datos del JSON.

Ruta ventas con v0

  1. Pega el prompt en v0.app y espera la vista previa.
  2. Pide cambios en lenguaje natural: "haz las tarjetas más grandes", "agrega un gráfico por proveedor".

Ruta código

  1. Crea la carpeta pulso-ventas y pide a Claude Code o Cursor un index.html con el prompt de arriba.
  2. Ábrelo con un servidor local, por ejemplo npx serve, para que el fetch funcione.

¿Sin v0 ni editor? Sube el Excel a Claude o ChatGPT y pídeles lo mismo: el dashboard llevará los datos dentro del archivo.

Reto 2 · Publícalo y crea tu primera API

Una API es una dirección web que responde datos. La tuya responderá preguntas como "¿cuánto vendimos en diciembre en el Norte?". En la sesión 3 la usará tu app de Lovable y en la sesión 4 tu bot de WhatsApp.

Ruta ventas con v0, solo con prompts

  1. En el mismo chat de v0, pega:
Agrega una ruta de API en /api/resumen que lea el mismo JSON y devuelva en JSON las ventas, el margen, el vencido por cobrar, las ventas por mes, por región y por canal, y el top 5 de productos. Que acepte filtros opcionales por mes, region, canal y vendedor en la URL, por ejemplo /api/resumen?mes=12®ion=Norte. Agrega el encabezado Access-Control-Allow-Origin: *.
  1. Pulsa Publish. v0 publica en Vercel y te da una URL.
  2. Prueba tu API en el navegador: tu-url.vercel.app/api/resumen?mes=12. Debe decir "venta": 67360.

Ruta código con GitHub y Vercel

  2. Sube la carpeta a GitHub y en Vercel: Add New → Project → Import → Deploy.

El plan gratuito de Vercel es para uso personal y no comercial. Tu URL y tu API son públicas: úsalas solo con datos de práctica.

Reto 3 · Tu agente analista

No un dashboard estático: un agente que conversa, consulta tu API como herramienta y responde con cifras reales. Así piensa: recibe la pregunta, decide qué datos necesita, llama a /api/resumen con filtros y responde mostrando qué consultó.

Modelos gratis para tu agente

  • OpenRouter (https://openrouter.ai): una sola clave para cientos de modelos. Los gratis terminan en :free. Sin tarjeta tienes 50 solicitudes al día; con una recarga única de US$ 10 sube a 1.000 al día. Elige en openrouter.ai/models uno gratis que soporte herramientas.
  • NVIDIA Build (https://build.nvidia.com): modelos abiertos alojados por NVIDIA, gratis para prototipos y compatibles con la API de OpenAI.

Paso a paso

  1. Crea tu clave en openrouter.ai/keys o en build.nvidia.com.
  2. Agrega a tu proyecto la plantilla probada: api/chat.js y chat.html:
    https://unimauro.github.io/curso-ia-productividad/material/agente/api/chat.js
    https://unimauro.github.io/curso-ia-productividad/material/agente/chat.html
    , junto a tu api/resumen.js.
  3. En Vercel: Settings → Environment Variables. Crea LLM_API_KEY con tu clave y LLM_MODEL con el modelo. Para NVIDIA agrega LLM_BASE_URL = https://integrate.api.nvidia.com/v1.
  4. Publica y abre tu-url.vercel.app/chat.html. Pregúntale: "¿Qué vendedor da más descuentos y cuánto margen pierde?".

Ruta ventas con v0

Agrega una página /chat con un agente llamado Analista Andina. Debe usar la API de OpenRouter con las variables de entorno LLM_API_KEY y LLM_MODEL, y tener una herramienta resumen_ventas que llame a mi /api/resumen con filtros de mes, región, canal y vendedor. Que muestre qué consultó y nunca invente cifras.

Ruta código con OpenCode

OpenCode (https://opencode.ai) es un agente de código abierto para la terminal, el escritorio o el editor. Trae modelos gratis y acepta tu clave de OpenRouter. En tu carpeta del proyecto ejecuta opencode y pídele: "Agrega a este proyecto el agente de chat de la plantilla y prepáralo para Vercel".

Regla de oro: la clave del modelo va en las variables de entorno de Vercel, nunca en el código ni en GitHub.

Reto 4 · Tablero vivo: editas la hoja y el dashboard cambia solo

El gerente no programa: edita una hoja de Google. Conectamos esa hoja a tu API, y tu dashboard se actualiza solo. Todo con prompts.

  1. Crea la hoja: en Google Sheets, Archivo → Importar → Subir el archivo ventas-2025.csv → Reemplazar hoja de cálculo.
  2. Publícala como CSV: Archivo → Compartir → Publicar en la web → elige la hoja → formato Valores separados por comas (.csv) → Publicar. Copia el enlace.
  3. Pide el cambio con un prompt en v0 o en tu agente de código:
Cambia /api/resumen para que lea los datos desde este CSV publicado de Google Sheets, en lugar del JSON: PEGA_AQUI_TU_ENLACE La API debe leer el CSV del lado del servidor, convertir cada fila en un objeto con los mismos campos y no guardar los datos en caché más de 60 segundos. Haz que el dashboard lea todo desde /api/resumen, que se refresque solo cada 60 segundos y que muestre "Actualizado a las HH:MM".
  1. Publica de nuevo con Publish en v0, o sube el cambio a GitHub.
  2. Pruébalo: en la hoja, cambia la venta de una fila de diciembre, por ejemplo agrégale un cero. Google tarda unos minutos en actualizar el CSV publicado; luego tu dashboard y tu API muestran el nuevo total.

Por qué la API y no el dashboard: Google bloquea que una página web lea su CSV directamente desde el navegador. Tu API lo lee desde el servidor, sin ese bloqueo. Además, cuando en la sesión 4 el bot de WhatsApp consulte tu API, responderá con lo que el gerente tenga en su hoja.

Publicar en la web hace pública la hoja para cualquiera con el enlace. Úsalo solo con datos de práctica.

Opción sin prompts: Data Studio

Si prefieres arrastrar y soltar: en Data Studio, que hasta abril de 2026 se llamó Looker Studio, elige Crear → Informe → Hojas de cálculo de Google, selecciona tu hoja y agrega gráficos por mes, región y canal. Cuando cambies la hoja, pulsa Actualizar datos.

Reto extra · MCP: conecta Claude y ChatGPT a los datos

MCP (Model Context Protocol) es el estándar abierto para conectar una IA con tus datos y herramientas: el "USB-C" de la IA. Un servidor MCP se construye una vez y lo usan Claude, ChatGPT, Cursor u OpenCode.

Cliente¿Puede usar un MCP propio?
Claude gratisSí: 1 conector personalizado
Claude Pro o superiorSí: varios conectores
ChatGPT gratisNo: solo apps del catálogo. Usa tu API pegando la URL
ChatGPT Plus o superiorSí, en modo desarrollador
Cursor y OpenCodeSí

Crea tu propio servidor MCP en v0 o Vercel

Tu proyecto puede tener las tres puertas a la vez: /api/resumen para tu app y tu bot, /api/chat para tu agente y /mcp para Claude, Cursor u OpenCode. Vercel publica servidores MCP con su paquete mcp-handler.

  1. Ruta ventas En el mismo chat de v0, pega este prompt y luego pulsa Publish:
Agrega un servidor MCP a este proyecto usando el paquete mcp-handler de Vercel, en la ruta /mcp. Registra dos herramientas: 1. resumen_ventas: filtros opcionales mes, region, canal y vendedor; devuelve lo mismo que /api/resumen. 2. top_productos: parámetro opcional limite; devuelve los productos más vendidos con su venta. Sin autenticación, porque los datos son ficticios. Al final dime la URL para agregarla como conector en Claude.
  1. Ruta código Parte de la plantilla oficial vercel-labs/mcp-for-next.js, agrega tus herramientas con tu agente de código y publícala en Vercel.
  2. Tu URL de conector será https://tu-proyecto.vercel.app/mcp.

¿Se trabó? Usa el servidor MCP del curso para seguir: https://ai.tunky.net/encuesta-api/mcp. Tiene las mismas cifras.

Extra · Skills: enséñale a la IA tu forma de trabajar

Una skill es un manual que la IA carga sola cuando la tarea lo necesita: un método, un formato, unas reglas. MCP le da acceso a tus datos; la skill le enseña cómo trabajar con ellos.

En Claude, también con el plan gratis

  1. En https://claude.ai: Configuración → Capacidades y activa ejecución de código y creación de archivos.
  2. Descarga la skill del curso: https://unimauro.github.io/curso-ia-productividad/material/skills/analista-financiero.zip. Trae el método que salió de la tarea 1: fórmulas visibles, descomposición de la causa, anomalías y verificación.
  3. Personalizar → Skills → + → Crear skill → Subir una skill y elige el ZIP.
  4. Sube el Excel de ventas y pide un análisis: Claude aplica el método solo.

En ChatGPT

Las Skills nativas de ChatGPT son de los planes de empresa. Con el plan gratis, crea un Proyecto y pega el contenido del archivo SKILL.md en sus instrucciones.

Crea la tuya

Una skill es una carpeta con un archivo SKILL.md: un encabezado con name y description, y debajo las instrucciones. Pídele a Claude: "Crea una skill para que analices mis ventas como lo hicimos hoy" y súbela comprimida en ZIP.
